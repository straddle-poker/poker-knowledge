# Pressure Systems (Lex Veldhuis / BBZ)

Pressure Poker Systems — the aggression/pressure layer of the BBZ systems ecosystem. Four human-executable systems, one per course module, each with buckets, decision rules, sizings, hand examples, quiz spots and Q&A.

**Provenance:** reconstructed from free public sources (BBZ blog, GTO Wizard, Upswing, SplitSuit) — NOT course transcripts. Ranges and heuristics are approximations grounded in the cited articles; each file's frontmatter carries its source URLs.

- [P2 — Facing Squeezes](P2 - Facing Squeezes.md) — Facing Squeezes (opener vs sandwiched response, call-or-fold equilibrium)
- [P3 — Flop Big-Betting vs BB](P3 - Flop Big-Betting vs BB.md) — Flop Big-Betting vs BB (nut advantage, overbet sizing, "did the board change?")
