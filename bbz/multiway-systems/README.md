# Multiway Poker Systems

Multiway Poker Systems (BBZ) — 11 human-executable systems for 3+ player pots, organized around the **clock**: every decision point has an expected owner of aggression, and each system covers what happens when that player misses their turn with it. Each `MW<n> - <title>.md` file is one system: buckets, decision rules, sizings and exceptions, with source URLs in its frontmatter.
