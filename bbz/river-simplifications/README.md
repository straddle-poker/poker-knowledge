# River Simplifications

River Simplifications (BBZ) — 7 river toy-game systems at SPR 1, 2 and 5, each isolating one variable: symmetric ranges, condensed IP/OOP, traps, small bets, and the polar-OOP-vs-condensed-IP collision. Each `RS<n> - <title>.md` file is one toy game: setup, solved math, buckets, decision rules and sizings, with source URLs in its frontmatter.
