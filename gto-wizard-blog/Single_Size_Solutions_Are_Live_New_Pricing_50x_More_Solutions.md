## **New: Custom Preflop Tree Builder**
We’ve shipped a new Custom Preflop Tree Builder for Ultra users, making it significantly faster and easier to build, edit, and solve your own preflop trees.
The new builder gives you granular control over preflop configuration:
  * Apply different sizing schemes to different positions
  * Set in-position and out-of-position raise sizes separately
  * Scale raise sizes when facing limpers or cold-callers
  * Choose which positions can limp or cold-call

Once your tree is built, you can fine-tune it in the tree editor and save it for future use.
To get started, create a new multiway preflop solution and open the ‘Bet sizes’ dropdown. From there, you can copy sizing schemes between positions, define IP and OOP raise sizes separately, and adjust how sizes scale with cold-callers or limpers.
![](https://blog.gtowizard.com/content/2026/04/6-1-1.png)
For example, here we’ve set BB’s 3-bet size to 9bb IP, meaning we’re raising the SB open. And we’ve set the OOP raise to 12.5bb, plus 2bb per cold-caller. So if the BTN opens, we’ll raise to 12.5bb. If the CO opens and BTN calls, we’ll 3-bet to 14.5bb.
