# Small Blind Mastery: Limped Pots

Small Blind Mastery: Limped Pots (BBZ) — 8 human-executable systems for blind-vs-blind limped pots, covering the preflop limp/raise/fold structure by stack depth, the flop from both seats, the isolation response, geometric turn sizing, river value and bluff selection, and the exploits that punish players unfamiliar with limped pots. Each `LP<n> - <title>.md` file is one system: buckets, decision rules, sizings and exceptions, with source URLs in its frontmatter.
